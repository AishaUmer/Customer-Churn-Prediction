# Customer-Churn-Prediction
Retaining existing customers is significantly more cost-effective for banks than acquiring new ones. Customer churn—when a client closes their account or stops doing business with a financial institution—directly impacts a bank's profitability.
This project features a machine learning solution to predict customer churn for a banking institution. The project walks through end-to-end data preparation, categorical encoding, model training, and feature importance analysis to identify why customers leave.

## 🚀 Project Overview

The objective is to analyze customer demographics and account behaviors to predict whether a customer will exit the bank (`Exited` = 1). Identifying high-risk individuals allows marketing and retention teams to intervene early with targeted incentives.

## 🛠️ Tech Stack & Dependencies

* **Python 3.x**
* **Pandas & NumPy**: For data ingestion, cleaning, and one-hot encoding.
* **Matplotlib & Seaborn**: For plotting demographic trends and feature impacts.
* **Scikit-Learn**: For data splitting, model training, and extracting feature importance weights.
